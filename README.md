# Manual Testing Metrics Practice

This project is created to practice and understand **software testing metrics** used in manual testing.

## 📌 Project Overview

The project focuses on analyzing test cases and calculating important testing metrics based on a sample application, such as an **e-commerce cart management system**.

## 📊 Metrics Covered

* Test Coverage
* Requirement Coverage
* Test Case Execution Rate
* Pass Percentage
* Fail Percentage
* Defect Density
* Defect Detection Percentage
* Defect Leakage
* Defect Severity
* Defect Priority

## 🧪 Testing Activities

* Identify application requirements
* Create test scenarios and test cases
* Execute test cases
* Record Pass/Fail results
* Identify and document defects
* Map defects to requirements
* Calculate testing metrics
* Analyze the overall testing status

## 🎯 Objective

The main objective is to gain practical knowledge of how **manual testing metrics** are calculated and used to measure:

* Testing progress
* Test coverage
* Product quality
* Defect status
* Testing effectiveness

## 🛠️ Tools Used

* Manual Testing
* Excel / Spreadsheet
* GitHub
